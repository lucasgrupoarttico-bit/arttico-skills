# 00 — Descobrir novas skills

**Quando usar:** você quer fazer alguma coisa e não sabe se já existe skill pronta pra isso, aqui dentro ou no ecossistema do Claude Code.

| Skill | O que faz | Chame assim |
|-------|-----------|-------------|
| [`find-skills`](find-skills/) | Procura e instala skills públicas a partir do que você quer fazer. Responde perguntas do tipo "existe uma skill que faz X?" | "tem alguma skill pra fazer X?" |

## Instalação

```bash
cp -r skills/00-descobrir-novas-skills/find-skills ~/.claude/skills/
```

> A pasta numerada só organiza este repositório. Copie **a pasta da skill**, nunca a pasta da categoria.
