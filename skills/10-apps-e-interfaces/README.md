# 10 — Apps e interfaces

**Quando usar:** o entregável não é campanha nem página, e sim um produto: ferramenta interna, SaaS ou qualquer tela que precise ficar bonita.

| Skill | O que faz | Chame assim |
|-------|-----------|-------------|
| [`criar-app`](criar-app/) | Tira um app/SaaS do papel: entrevista, plano de ação, protótipo navegável, aprovação, banco no Supabase, app funcional e deploy na Vercel. | "quero criar um app que faz X" |
| [`frontend-design`](frontend-design/) | Direção de design visual pra interface nova: estilo, tipografia e escolhas que fogem do template padrão. | "melhora o visual dessa tela" |
| [`awesome-design-md`](awesome-design-md/) | Aplica o design system de marcas reais (Stripe, Notion, Apple, Figma…) na geração de UI. | "faz essa tela com a cara do Stripe" |

## Instalação

```bash
cp -r skills/10-apps-e-interfaces/criar-app ~/.claude/skills/
```

> A pasta numerada só organiza este repositório. Copie **a pasta da skill**, nunca a pasta da categoria.
