# Índice das skills

As pastas seguem a ordem do ciclo de um cliente: planejar → pesquisar → subir campanha → otimizar → produzir criativo → medir → reportar. Abra a pasta da etapa em que você está; cada uma tem seu próprio README explicando as skills de dentro.

## [00 — Descobrir novas skills](00-descobrir-novas-skills/)
*Não sabe se já existe skill pro que você quer fazer.*

| Skill | O que faz |
|-------|-----------|
| [`find-skills`](00-descobrir-novas-skills/find-skills/) | Procura e instala skills públicas a partir do que você quer fazer |

## [01 — Planejamento de cliente](01-planejamento-de-cliente/)
*Entrou cliente novo e falta o planejamento de campanha.*

| Skill | O que faz |
|-------|-----------|
| [`plano-acao`](01-planejamento-de-cliente/plano-acao/) | Plano de ação completo: plataforma, campanha, avatar e funil, em deck 16:9 |

## [02 — Pesquisa e concorrência](02-pesquisa-e-concorrencia/)
*Precisa saber o que o mercado já está rodando.*

| Skill | O que faz |
|-------|-----------|
| [`analise-concorrentes`](02-pesquisa-e-concorrencia/analise-concorrentes/) | Concorrentes no Meta Ads, Google Ads, Instagram e TikTok, com criativo validado |
| [`apify`](02-pesquisa-e-concorrencia/apify/) | Coleta via Apify: leads Google Maps, Instagram, TikTok e Facebook Ad Library |
| [`yt-research`](02-pesquisa-e-concorrencia/yt-research/) | Pesquisa de mercado no YouTube: dores, hooks e objeções pra copy |

| [`google-ads-ratos`](03-campanhas-meta-e-google/google-ads-ratos/) | Google Ads com GAQL: campanhas, keywords, search terms, RSA, negativas |
